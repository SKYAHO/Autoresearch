## 트랙 A — #299 Feast PIT 전환 배포 lockstep 마무리 (즉시, 내 레인)

가장 싸게 닫히고, 닫으면 training-serving skew 리스크가 실제로 사라진다. 코드는 이미 main에 있고
배포 배선만 남았다.

1. **feast 앱 이미지 release** — 머지 SHA로 트리거
   ```bash
   gh workflow run release.yml -f source_sha=704e91dfd17375b5f115986b132818f8481b5c65
   ```
   release.yml은 `release`/`workflow_dispatch` 트리거라 main 머지로 자동 실행되지 않는다.
   실행되면 feast(+app/training) 이미지를 GAR에 빌드·푸시하고 digest 승격 PR을 자동 생성한다.
2. **digest 승격 PR 머지** — airflow의 `AUTORESEARCH_FEAST_IMAGE`를 새 digest로 갱신하는 자동 PR.
3. **airflow #177 머지** — 반드시 2번 뒤에. DAG feast-only 전환(image→feast, DuckDB 인자 4개 제거,
   `GCS_REGISTRY_PATH`/`GCS_STAGING_LOCATION` 주입, memory_request 5Gi). 순서가 뒤집히면 DAG이
   C2 코드가 없는 옛 이미지를 부른다.
4. **실 학습 DAG 1회 feast로 완주 확인** → #299 EPIC 실질 종료.

주의: release 트리거는 GAR 프로덕션 배포라 사람이 실행한다(에이전트 자동 실행 금지).
